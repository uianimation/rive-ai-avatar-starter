# Contributing

Use Node 22.12+ and `npm ci`. Run `npm run check` before opening a pull request. Keep changes focused and include steps to reproduce any bug. For rendering issues, include browser/runtime versions, artboard and State Machine names, binding mode and a minimal asset you have permission to share.

Do not include API keys, client files, private project briefs or assets without redistribution permission. Changes to control ranges/names are contract changes and must update documentation and tests together. New dependencies should have a clear purpose.

Issues are for reproducible bugs and feature proposals. For paid character work, use the Mascot Engine links in the README rather than posting confidential project details in public issues.
